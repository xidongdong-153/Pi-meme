# UI 体验与动效

Pi-meme 面向长时间使用聊天、项目和工具面板完成开发任务的用户。界面保持轻松、克制，品牌图标可以带一点俏皮。高频操作优先保证响应快、文字清晰、位置稳定。

本规范适用于后续新增和修改的导航、Tab、列表详情、面板与异步加载。现有接入范围见文末；未列出的页面按修改范围逐步采用，不代表全应用已经完成改造。

## 切换与反馈

- 点击后立即更新选中态或等待状态，不等请求结束才反馈。数据就绪后立即显示，不为动画增加固定等待时间。
- 平级菜单不用左右滑动暗示前进或后退。一般内容可短淡入；设置分类直接呈现固定标题、说明和操作，只过渡依赖数据的文字与区域，避免整屏先消失再出现。
- 顶栏、导航轨、内容外框与背景保持稳定，只让发生变化的内容过渡。不要在父子层同时叠加入场动画。
- 同一目标重复点击、聊天流式输出、后台刷新不重复播放页面入场。快速连续切换直接响应最后一次选择，取消未完成动画，不排队、不锁住菜单。
- 草稿、输入框、滚动位置和已保留页面不能为了重播动画而重新挂载。需要保留实例时，监听目标变化触发动效，不给整个业务树换 `key`。
- 加载期间保留已有列表。首次没有数据时保留标题、工具栏和内容区域尺寸；等待图标和文字可延迟 160ms 出现，快速响应时不闪出转圈。已有数据、错误和操作反馈不能被这个延迟隐藏。
- 目标改变时不能把旧内容当成新内容继续操作。旧内容如需短暂保留，应设置 `inert` 和 `aria-hidden`；等待区域提供 `aria-busy`，等待文字使用 `role="status"`。
- 空状态仅在加载完成且确实没有数据时出现。加载失败显示具体原因和重试入口，不在失败后留下永久骨架屏。

## 会话状态与工具保留

会话、资料空间、定时任务、插件与技能共用左侧栏的开合与宽度，由客户端外层统一管理，同一窗口内跨页面、会话与 Host 共享，并保存到客户端本地存储；切换页面、会话、进入新聊天和删除会话不重置这些布局偏好。完整视图／分栏模式同样由客户端管理。窄窗口空间不足时自动收起左栏，点击顶栏展开按钮以浮层打开，不挤压正文。

这些侧栏复用 [WorkspaceSidebar](../packages/app-ui/src/layout/workspace-sidebar.tsx) 的固定栏、浮层、拖拽与折叠按钮。折叠后悬停当前页面的导航轨入口可临时查看；键盘聚焦入口后按右方向键打开，Escape 关闭并返回入口。浮层不改变保存的开合与宽度，关闭及退场时立即设置 `inert` 和 `aria-hidden`，同一份内容保留表单与滚动位置，不重复挂载列表。

新增有列表或分类侧栏的内置页面，优先组合 [SidebarWorkspace](../packages/app-ui/src/layout/sidebar-workspace.tsx)，传入客户端 `SidebarLayout`、导航、侧栏内容和正文；业务包可通过 `renderLayout` 交给组合根装配，避免反向依赖 `app-ui`。复杂工作区可直接组合 `useWorkspaceSidebar`、`WorkspaceSidebar` 和 `SidebarToggle`。业务页面不再单独声明侧栏宽度或用响应式类隐藏侧栏；常驻但不可见的工作区必须传入 `visible={false}`，暂停自动折叠与快捷键。

右栏开合、宽度、工具标签、活动标签以及完整视图中显示聊天或工具的选择按 Host 与稳定会话 ID 保存。新聊天使用独立草稿身份，分栏时右栏默认关闭，不继承上一会话；草稿创建为正式会话后迁移右栏状态。不同设备各自保留布局。外观由窗口内唯一所有者通过外观 Host 保存到 `config/app.json`；Desktop 多服务界面切换 Host 时继续使用客户端本地 Host 的外观，独立 Web 使用连接入口的 Host。

外观修改立即预览，只有 Host 落盘确认后显示“已保存”。读取失败、保存失败和冲突保留可操作的错误与重试入口，不用旧响应覆盖新预览。切换主题保留显式字体与字形；临时预览、系统明暗变化和字体枚举不写配置。其他客户端的外观事件与重新连接只重新读取，未确认修改按冲突规则处理。

Desktop 正常关窗、退出、受控重新加载和存储维护使用同一准备屏障，保存期间暂时停止新的外观编辑。失败、超时或取消离开后恢复编辑；超时显示保存尚未确认，不能直接宣称保存失败或成功。普通关闭可明确选择放弃本次未确认修改；维护失败时保留 Host，不提供绕过保存的选项。原有文件、聊天、浏览器、插件页和指令离开守卫继续有效；外观保存成功不能替它们放行。独立 Web 的未确认修改使用浏览器原生离开提示，强关和崩溃不保证保存。

切换会话或收起右栏时，已打开的工具保留实例和 DOM；隐藏视图不接收键盘输入，不抢焦点。刷新界面后恢复布局与文件标签，并重新附着仍存活的 Host 终端和 Desktop 网页。Host 重启不恢复终端进程；Desktop 进程重启不承诺恢复未提交的网页表单。

工具目录按数据是否可查看显示入口。上下文窗口要求正式会话记录和真实主请求摘要；变更要求工作区修改或当前分支的轮次差异；计划、活动、子代理、来源、草图和会话树分别依赖自己的内容。文件、终端、网页和侧边聊天可主动使用，不要求已有聊天消息。已打开的文件与网页实例不在目录重复列出。

入口显隐和标签保留独立：数据归零只隐藏新入口，已打开或恢复的标签继续存在，内容更新为空态；加载、断线和读取失败保留同一目标最后确认的内容并显示必要错误与重试。首次未知不显示内容型入口，不能把失败当成空数据。确认插件卸载、撤权或代次替换时清理相关实例和订阅，不清理其他会话的普通保留视图。

变更入口使用轻量摘要，不通过挂载内容面板或读取完整差异判断。目录在前台时按事件、重新聚焦及约 10 秒兜底更新；完整内容由可见面板按需读取。入口打开时定位有内容的范围，消息操作定位指定轮次，恢复标签保留原选择。干净仓库仍可通过 Git 菜单的“查看变更”主动比较分支或提交。

切换会话时定位到最新消息，包括切回保留的面板；同一会话临时隐藏再显示时保留阅读位置。聊天阅读位置按会话保存在当前窗口的 `sessionStorage`，记录底部状态、消息锚点和偏移，供刷新界面时恢复；恢复较早的锚点时按需读取历史。会话删除事件清理关联布局和工具引用。

实现入口为 [WorkspacePanels](../packages/app-ui/src/layout/workspace-panels.tsx)、[RetainedToolPanels](../packages/app-ui/src/layout/retained-tool-panels.tsx)、[useSidebarLayout](../packages/app-ui/src/layout/use-sidebar-layout.ts)、[useWorkspaceView](../packages/app-ui/src/layout/use-workspace-view.ts) 和 [useConversationScroll](../packages/chat/src/ui/conversation/use-conversation-scroll.ts)。

## 新聊天草稿

同一 Host、同一窗口保留一份新聊天草稿。点击新聊天或选择其他项目时复用该草稿；进入历史会话后，显示该会话自己的输入，再返回新聊天时恢复原草稿。顶部新聊天采用当前会话的项目，项目旁入口采用指定项目。

文字与可序列化引用按窗口保存，刷新后恢复；附件只在窗口内保留。首次提交成功后消费对应草稿，失败保留内容，迟到响应不得覆盖后来输入的内容。不同 Host 和窗口的草稿独立。

同目标已就绪时重复点击不重新创建会话、不重播正文入场。新聊天内切项目保持编辑器节点，项目准备信息只在项目控件附近延迟出现；输入仍可编辑，发送等待目标就绪。运行时会话标识继续用于请求、权限、插件与工具归属，不使用编辑器身份替代。

## 动效参数

| 场景               | 默认效果                                    | 时长  |
| ------------------ | ------------------------------------------- | ----- |
| 导航悬停、文字颜色 | 颜色过渡                                    | 120ms |
| 导航选中底色       | 透明度 0.4 → 1，缩放 0.94 → 1；图标位置不动 | 160ms |
| 平级页面、分类内容 | 透明度 0.65 → 1，不平移                     | 180ms |
| 动态文本替换       | 旧文字淡出、新文字淡入，共用所在位置        | 180ms |
| 异步区域展开       | 网格行从 0fr 到 1fr，同时淡入               | 240ms |
| 异步等待提示       | 延迟 160ms 后淡入；完成立即移除             | 120ms |
| 已有会话就绪       | 淡入，最多上移 6px                          | 200ms |
| 新会话品牌图标     | 轻微倾斜后回正                              | 280ms |

内容和选中底色使用 `cubic-bezier(0.22, 1, 0.36, 1)`。以 `opacity` 和 `transform` 为主，不对整页使用 `transition: all`、模糊或大幅缩放。不使用弹跳、连环错峰入场和循环装饰动画。已有侧栏开合继续使用自己的布局过渡。

系统开启 `prefers-reduced-motion: reduce` 或应用开启“减少动态效果”时，新接入的切换关闭动画，保留选中态、焦点和等待说明。切换过程中开启该选项也应立即停止动画。

## 实现入口与接入范围

- 一级导航：[use-navigation-motion.ts](../packages/app-ui/src/layout/use-navigation-motion.ts) 在首页、资料空间、项目、定时任务、插件与技能、设置及不同插件之间切换时，对可见 `.content-frame` 的直接子内容做淡入；不改变导航状态和页面生命周期。
- 导航选中底色：[AppRail](../packages/app-ui/src/layout/app-rail.tsx) 使用 `.app-rail-entry`；样式在 [global.css](../packages/app-ui/src/global.css)。
- 局部内容入场：[FadeContent](../packages/ui/src/components/fade-content.tsx) 使用 `.ui-content-enter`，用于右侧栏 Tab 和启动画面。仅在原本就需要挂载的新内容上使用；不要包裹已有页面后再通过更换 `key` 重播动画。
- 设置分类：[SettingsPage](../packages/app-ui/src/settings/settings-page.tsx) 直接渲染固定界面，不使用分类骨架或整页淡入。快捷键等同步页面立即可用；外观、指令等页面保留已知结构，未知配置读取完成前禁用相关操作。刷新保留已有数据，不为动效增加固定等待。
- 动态文字：[CrossfadeText](../packages/ui/src/components/crossfade-text.tsx) 将新值立即提交，旧文字仅作短暂的视觉过渡并从辅助技术中隐藏。有限的可能文案可以用 `reserve` 预留尺寸；输入框不替换实例、不为重播动效更换 `key`。
- 异步内容：[RevealContent](../packages/ui/src/components/reveal-content.tsx) 常驻容器，在 `ready` 变化时展开，例如服务商、技能、MCP 列表和用量图表。固定标题与操作放在容器外，后台刷新保持 `ready`，不反复收起；隐藏区域使用 `inert` 和 `aria-hidden`。系统或应用减少动态效果时直接切换。
- 首次等待提示：`.ui-loading-delayed` 在 [tokens.css](../packages/ui/src/tokens.css) 中维护，目前用于项目空列表读取提示和定时任务的懒加载提示。它只延迟视觉提示，不延迟请求和数据提交。
- 会话切换：[WorkspaceContent](../packages/app-ui/src/layout/workspace-content.tsx) 继续独立处理旧内容隔离、等待和会话入场，不改为一级导航动效。

后续页面优先复用这些入口和参数。需要不同效果时，在对应需求中说明是哪种空间关系或状态变化，不仅因为“想加动画”另建一套实现。

## 资料空间

资料空间复用 `SidebarWorkspace`，全部、图像与中央图片详情进入同一导航历史。首次访问后保留页面实例；隐藏时向公共侧栏和数据入口透传 `visible={false}`，暂停快捷键与订阅，不重置其他页面共用的侧栏偏好。详情按 Host、服务与稳定图片 ID 定位，列表刷新与重排不改变当前目标。

中央详情嵌入 [ImagePreviewStage](../packages/chat/src/ui/content/image-viewer.tsx)，默认不自动抢焦点，不使用模态焦点锁。聊天中的 `ImageViewer` 继续保留原有 Dialog、关闭后的焦点返回与键盘行为。

创建图像与基于此图复用目标 Host 的新聊天草稿和唯一输入框。跨 Host 先经过离开守卫，再由对应控制器准备图片附件；准备完成后追加创作意图与附件，保留已有草稿。入口只预填，不自动提交，也不在导航时触发生图计费。切页、切 Host 或准备失败后，迟到请求不改写另一目标的输入。

## 悬停提示

所有悬停说明复用 [Tooltip](../packages/ui/src/components/ui/tooltip.tsx)，不在界面元素上使用浏览器原生 `title`，也不另写气泡的背景、边框、圆角或阴影。页面标题、折叠分组标题、iframe 的无障碍名称不属于悬停提示。

- 已完整可见的名称、状态和带字操作不再用气泡复述。子代理、会话树等列表通过菜单或点击入口查看详情。
- 会话栏的会话和项目行复用 [SidebarHoverCard](../packages/workspace/src/ui/sidebar/sidebar-hover-card.tsx)，悬停 300ms 后在右侧展示卡片。会话卡片显示完整标题、来源、最近活动和所属项目；项目卡片显示名称、置顶、会话数、路径和编辑入口，远程项目继续提供连接状态与重试操作。鼠标可移入卡片；离开行与卡片后延迟 180ms 关闭，滚动列表、拖动、隐藏侧栏或按 Escape 立即关闭。键盘聚焦名称可查看，按右方向键进入卡片。行内图标操作继续使用普通提示；会话定时安排、父会话等完整信息仍由菜单中的“会话详情”查看。
- 被截断的文字使用 `OverflowTooltip content={完整文字}` 包住实际省略的文字元素，仅溢出时补全；不要测量外层按钮代替文字。会话栏标题复用 `SidebarTitle` 保持单行省略，完整名称由侧边卡片展示，不滚动文字或叠加气泡。完整路径、真实链接目标与禁用原因有额外信息，不能因为名称未截断就移除。
- 图标含义、不可用原因、异常、输入限制和必要指标说明保留。普通提示使用 `TooltipHint content={说明}` 包住原元素；已有复杂内容继续组合 `Tooltip`、`TooltipTrigger` 和 `TooltipContent`。气泡统一换行、视口避让与减少动态效果行为；`aria-label` 等无障碍名称继续保留。
- `TooltipHint` 放在菜单或 Popover 的触发器外，确保实际按钮仍接收它们的事件、ref 和展开状态。禁用按钮使用保持原布局的 `span` 作提示触发器，禁用时让该触发器可聚焦，保留不可用原因。
- 输入框标签、CodeMirror 等命令式 DOM 用 `data-tooltip` 保存说明，由所在容器的 `DelegatedTooltip` 展示；节点替换、移除、滚动和输入时清理旧提示。图表受控提示使用 `AnchoredTooltip`，共享同一气泡与定位行为。
- 包含按钮或链接的预览保留 Popover 交互，普通预览复用 `tooltipSurfaceClassName`；会话栏的侧边卡片使用 Popover 的圆角面板和主题背景，统一宽度、间距与排版。

## 链接与图像预览

Markdown 文件标签页的图片读取器绑定该标签保存的会话，相对图片路径以文档所在目录为基准；切换当前聊天不改变已打开文件的读取目标。图片读取失败保留具体原因和重试入口，读取成功后可点击缩略图查看原图。

网页链接悬浮卡通过 Host 读取公开 HTTPS 页面的 HTML 头部，读到头部结束即停止下载，不因网页正文超过 1 MiB 而失败；头部仍有 1 MiB 上限，整个请求最多等待 12 秒。最多跟随三次重定向，每一跳重新校验公开地址并固定连接地址，相对封面与图标按最终页面地址及 `<base>` 解析。成功结果缓存五分钟，失败不缓存，可在卡片中重试或重新悬停加载。

系统 DNS 全部返回代理 Fake-IP（`198.18.0.0/15`）时，仅内置网页预览使用固定 `1.1.1.1` 的 Cloudflare HTTPS DNS 查询原域名，再校验并固定到真实公开地址；不会放行 Fake-IP 或私网地址，不携带用户 Cookie、令牌或凭据。受限插件仍沿用原有网络权限、DNS 校验和完整响应大小限制。实现见 [link-preview.ts](../packages/host/src/link-preview.ts)、[link-preview-network.ts](../packages/host/src/link-preview-network.ts) 和 [LinkedFilePanel](../packages/app-ui/src/panels/linked-file-panel.tsx)。

## 检查方式

在实际页面检查以下行为，不用只断言 CSS 类名的测试代替体验检查：

1. 依次切换左侧菜单，再返回首页；外框和顶栏不闪，内容过渡结束后文字清晰，输入草稿仍在。
2. 连续快速点击不同入口；最终选中项与内容一致，没有动画队列、残留透明度或旧页面遮挡。
3. 分别检查快速加载、慢加载、后台刷新和失败；快速加载不闪等待图标，慢加载有状态说明，刷新保留已有列表，失败可重试。
4. 开启系统或应用减少动态效果，再切换；动画关闭，导航、焦点和状态反馈仍可用。
5. 用键盘切换并检查 Tab 焦点；隐藏的页面不可聚焦，无横向溢出。浅色、深色主题使用同一套参数。
