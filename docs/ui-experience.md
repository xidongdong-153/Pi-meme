# UI 体验与动效

Pi-meme 面向长时间使用聊天、项目和工具面板完成开发任务的用户。界面保持轻松、克制，品牌图标可以带一点俏皮。高频操作优先保证响应快、文字清晰、位置稳定。

本规范适用于后续新增和修改的导航、Tab、列表详情、面板与异步加载。现有接入范围见文末；未列出的页面按修改范围逐步采用，不代表全应用已经完成改造。

## 切换与反馈

- 点击后立即更新选中态或等待状态，不等请求结束才反馈。数据就绪后立即显示，不为动画增加固定等待时间。
- 平级菜单只做短淡入，不用左右滑动暗示前进或后退。内容从可读的低透明度恢复，避免整屏先消失再出现。
- 顶栏、导航轨、内容外框与背景保持稳定，只让发生变化的内容过渡。不要在父子层同时叠加入场动画。
- 同一目标重复点击、聊天流式输出、后台刷新不重复播放页面入场。快速连续切换直接响应最后一次选择，取消未完成动画，不排队、不锁住菜单。
- 草稿、输入框、滚动位置和已保留页面不能为了重播动画而重新挂载。需要保留实例时，监听目标变化触发动效，不给整个业务树换 `key`。
- 加载期间保留已有列表。首次没有数据时保留标题、工具栏和内容区域尺寸；等待图标和文字可延迟 160ms 出现，快速响应时不闪出转圈。已有数据、错误和操作反馈不能被这个延迟隐藏。
- 目标改变时不能把旧内容当成新内容继续操作。旧内容如需短暂保留，应设置 `inert` 和 `aria-hidden`；等待区域提供 `aria-busy`，等待文字使用 `role="status"`。
- 空状态仅在加载完成且确实没有数据时出现。加载失败显示具体原因和重试入口，不在失败后留下永久骨架屏。

## 会话状态与工具保留

左右栏开合、宽度、工具标签、活动标签和分栏／完整视图按 Host 与稳定会话 ID 保存到客户端本地存储。新聊天使用独立草稿身份，右栏默认关闭，不继承上一会话；草稿创建为正式会话后迁移状态。不同设备各自保留布局，外观作用于发起操作的客户端。

切换会话或收起右栏时，已打开的工具保留实例和 DOM；隐藏视图不接收键盘输入，不抢焦点。刷新界面后恢复布局与文件标签，并重新附着仍存活的 Host 终端和 Desktop 网页。Host 重启不恢复终端进程；Desktop 进程重启不承诺恢复未提交的网页表单。

聊天阅读位置按会话保存在当前窗口的 `sessionStorage`，记录底部状态、消息锚点和偏移；恢复较早的锚点时按需读取历史。会话删除事件清理关联布局和工具引用。

实现入口为 [WorkspacePanels](../packages/app-ui/src/layout/workspace-panels.tsx)、[RetainedToolPanels](../packages/app-ui/src/layout/retained-tool-panels.tsx)、[useSessionSidebar](../packages/app-ui/src/session/use-session-sidebar.ts) 和 [useConversationScroll](../packages/chat/src/ui/conversation/use-conversation-scroll.ts)。

## 新聊天草稿

同一 Host、同一窗口保留一份新聊天草稿。点击新聊天或选择其他项目时复用该草稿；进入历史会话后，显示该会话自己的输入，再返回新聊天时恢复原草稿。顶部新聊天采用当前会话的项目，项目旁入口采用指定项目。

文字与可序列化引用按窗口保存，刷新后恢复；附件只在窗口内保留。首次提交成功后消费对应草稿，失败保留内容，迟到响应不得覆盖后来输入的内容。不同 Host 和窗口的草稿独立。

同目标已就绪时重复点击不重新创建会话、不重播正文入场。新聊天内切项目保持编辑器节点，项目准备信息只在项目控件附近延迟出现；输入仍可编辑，发送等待目标就绪。运行时会话标识继续用于请求、权限、插件与工具归属，不使用编辑器身份替代。

## 动效参数

| 场景               | 默认效果                                    | 时长  |
| ------------------ | ------------------------------------------- | ----- |
| 导航悬停、文字颜色 | 颜色过渡                                    | 120ms |
| 导航选中底色       | 透明度 0.4 → 1，缩放 0.94 → 1；图标位置不动 | 160ms |
| 平级页面、分类内容 | 透明度 0.65 → 1，不平移                     | 180ms |
| 异步等待提示       | 延迟 160ms 后淡入；完成立即移除             | 120ms |
| 已有会话就绪       | 淡入，最多上移 6px                          | 200ms |
| 新会话品牌图标     | 轻微倾斜后回正                              | 280ms |

内容和选中底色使用 `cubic-bezier(0.22, 1, 0.36, 1)`。以 `opacity` 和 `transform` 为主，不对整页使用 `transition: all`、模糊或大幅缩放。不使用弹跳、连环错峰入场和循环装饰动画。已有侧栏开合继续使用自己的布局过渡。

系统开启 `prefers-reduced-motion: reduce` 或应用开启“减少动态效果”时，新接入的切换关闭动画，保留选中态、焦点和等待说明。切换过程中开启该选项也应立即停止动画。

## 实现入口与接入范围

- 一级导航：[use-navigation-motion.ts](../packages/app-ui/src/layout/use-navigation-motion.ts) 在首页、项目、定时任务、插件与技能、图像、设置及不同插件之间切换时，对可见 `.content-frame` 的直接子内容做淡入；不改变导航状态和页面生命周期。
- 导航选中底色：[AppRail](../packages/app-ui/src/layout/app-rail.tsx) 使用 `.app-rail-entry`；样式在 [global.css](../packages/app-ui/src/global.css)。
- 局部内容入场：[FadeContent](../packages/ui/src/components/fade-content.tsx) 使用 `.ui-content-enter`，现用于设置分类、右侧栏 Tab 和启动画面。仅在原本就需要挂载的新内容上使用；不要包裹已有页面后再通过更换 `key` 重播动画。
- 首次等待提示：`.ui-loading-delayed` 在 [tokens.css](../packages/ui/src/tokens.css) 中维护，目前用于项目空列表读取提示和定时任务的懒加载提示。它只延迟视觉提示，不延迟请求和数据提交。
- 会话切换：[WorkspaceContent](../packages/app-ui/src/layout/workspace-content.tsx) 继续独立处理旧内容隔离、等待和会话入场，不改为一级导航动效。

后续页面优先复用这些入口和参数。需要不同效果时，在对应需求中说明是哪种空间关系或状态变化，不仅因为“想加动画”另建一套实现。

## 检查方式

在实际页面检查以下行为，不用只断言 CSS 类名的测试代替体验检查：

1. 依次切换左侧菜单，再返回首页；外框和顶栏不闪，内容过渡结束后文字清晰，输入草稿仍在。
2. 连续快速点击不同入口；最终选中项与内容一致，没有动画队列、残留透明度或旧页面遮挡。
3. 分别检查快速加载、慢加载、后台刷新和失败；快速加载不闪等待图标，慢加载有状态说明，刷新保留已有列表，失败可重试。
4. 开启系统或应用减少动态效果，再切换；动画关闭，导航、焦点和状态反馈仍可用。
5. 用键盘切换并检查 Tab 焦点；隐藏的页面不可聚焦，无横向溢出。浅色、深色主题使用同一套参数。

代码修改仍按[测试](testing.md#日常验证与新增测试)执行检查；浏览器手工检查不等于打包或发布验收。
