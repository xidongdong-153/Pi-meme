# 项目文档

pi-meme 的 Desktop 和 Web 共用 Node Host。应用入口在 `apps/`，基础包与内置能力在 `packages/`，独立分发的 App 插件源码在 `plugins/`。

下列文档说明当前实现与操作方式，不代表本次执行过构建、业务测试或发布验收。

| 使用与部署 | [配置与安全](configuration.md)              | 模型、MCP、指令、凭据、快捷键与权限边界        |
| 使用与部署 | [数据目录与存储](storage.md)                | 文件布局、更改目录、缓存清理与升级恢复         |
| 使用与部署 | [Remote](remote.md)                         | HTTPS 部署、SSH 连接、认证与断线排错           |
| 开发与发布 | [开发指南](development.md)                  | 功能修改位置、UI 原语与静态资源                |
| 开发与发布 | [测试](testing.md)                          | 静态检查、文件选测、CI、平台验证与报告         |

维护时优先更新所属主题，其他页面用链接引用；安装步骤放在快速开始，检查命令放在测试，分发流程放在版本发布，数据路径和维护放在存储。文档中的源码链接相对于仓库，页面元数据的 `paths` 用于按源码检索。长期规则以 [AGENTS.md](../AGENTS.md) 为准。

个人笔记、Agent 接力日志、一次性迁移清单与验收流水不纳入项目文档；测试报告保存在 `out/tests/`，不提交。
