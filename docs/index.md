# 项目文档

pi-meme 的 Desktop 和 Web 共用 Node Host。应用入口在 `apps/`，基础包与内置能力在 `packages/`，独立分发的 App 插件源码在 `plugins/`。Bots 在 `apps/bot` 独立运行，维护自己的配置、Web 和数据。

下列主题说明当前实现与操作方式；源码核对、文档结构诊断和格式检查不代表功能、构建产物或发布已经验收。
