# 猫猫与品牌资源

角色以 [参考图](reference/avatar.jpg) 为准：方圆大头、奶白偏灰绿的哑光材质、粉鲑色耳内、黑色椭圆眼、三角鼻和 W 形微笑。保留旧电脑低多边形 3D 的分面和像素边缘，不加毛发、腮红或眼睛高光。角色职责由帽子、眼镜和手持道具区分。

图片使用内置 image_gen 逐张生成。[prompts.json](prompts.json) 保存每张图的完整提示词、参考图顺序和输出路径。先生成通用猫，再将参考原图和通用猫一起作为其他角色的输入；浅色桌面图标和应用内透明图标以深色桌面图标为编辑目标。默认用户头像与通用子代理头像共用同一张图。

| 目录或文件                         | 用途                                   | 尺寸与数量               |
| ---------------------------------- | -------------------------------------- | ------------------------ |
| `files/agents/`                    | 子代理任务场景，见下表                 | 256 × 256，20 张透明 PNG |
| `files/system-plugins/`            | Git、文件、终端                        | 256 × 256，3 张透明 PNG  |
| `files/system-skills/`             | 技能创建、插件创建                     | 256 × 256，2 张透明 PNG  |
| `files/commands/`                  | 斜杠菜单的内置命令                     | 256 × 256，4 张透明 PNG  |
| `files/profile/default-avatar.png` | 默认用户头像                           | 512 × 512，透明 PNG      |
| `files/brand/`                     | 界面品牌图标，深浅主题共用同一透明图案 | 128 × 128，2 张透明 PNG  |
| `files/desktop/dock/`              | Dock 图标，深浅两版                    | 512 × 512，2 张透明 PNG  |
| `files/desktop/icons/`             | 桌面应用图标，深浅两版                 | 2 个 ICNS、2 个 ICO      |

导出时清除角色透明区域的分离残片，收紧原始蒙版边缘，并将主体居中到画布的 90%。应用内品牌图标仅保留白猫与键盘，两张主题 PNG 内容相同，沿用现有文件名。桌面图标使用统一圆角蒙版，底板占画布的 88%，四边透明留白各 6%。同一主题的 Dock PNG、ICNS 和 ICO 从同一张 1024 × 1024 图标导出。

ICNS 包含 16、32、64、128、256、512、1024px 表示；ICO 包含 16、32、48、64、128、256px 表示。替换图片时覆盖同名文件，保留 [builtin.ts](src/builtin.ts) 的头像顺序和引用路径。

[总览图](preview.png) 展示原图、基础角色与两版桌面图标，分别检查浅底、暗底，以及 16、24、32、48px 的缩小效果。

[应用内透明图标预览](brand-preview.png) 展示侧栏深色、内容区深色、浅色和灰蓝色背景下的 16、20、24、32、64px 效果。

## 子代理场景

`spawn_agent` 的可选参数 `avatar` 使用下表的场景 ID。例如：

```json
{ "task_name": "security_audit", "message": "检查认证与权限边界", "avatar": "security" }
```

显式指定的头像优先于任务名称匹配。不填写时按中英文职责名称匹配；未识别的名称保留原来 8 张头像的稳定分配结果。头像只影响展示，不改变工具、权限或任务模式。`followup_task` 与 Host 重启后保留已配置的头像，新建后代不继承父代理的头像。

| 场景 ID        | 用途       | 图像特征               |
| -------------- | ---------- | ---------------------- |
| `general`      | 通用       | 基础白猫               |
| `research`     | 研究       | 侦探帽、放大镜         |
| `plan`         | 计划       | 紫色工程帽、图纸       |
| `code`         | 编码       | 深蓝眼镜、电脑         |
| `review`       | 审查       | 金色眼镜、检查板       |
| `test`         | 测试       | 绿色护目镜、瓢虫       |
| `design`       | 设计       | 珊瑚色贝雷帽、画笔     |
| `docs`         | 文档       | 灰蓝眼镜、书           |
| `frontend`     | 前端       | 青蓝眼镜、界面板       |
| `backend`      | 后端       | 靛蓝领巾、服务器       |
| `database`     | 数据库     | 灰蓝头带、数据库圆柱   |
| `devops`       | 运维       | 蓝色工程帽、云与齿轮   |
| `security`     | 安全       | 绿色守卫帽、盾牌与锁   |
| `debug`        | 调试       | 橙色头灯、机械虫       |
| `performance`  | 性能       | 蓝色头带、秒表         |
| `refactor`     | 重构       | 青绿色工作帽、扳手     |
| `browser`      | 浏览器验证 | 淡紫耳机、浏览器检查板 |
| `data`         | 数据分析   | 淡紫眼镜、柱状图       |
| `product`      | 产品       | 黄色领巾、需求便签板   |
| `localization` | 本地化     | 蓝色软帽、地球仪       |

图片位于 `files/agents/<场景 ID>.png`，均为 256 × 256 透明 PNG。[20 种场景总览](agent-scenes-preview.png) 展示全部头像及缩小效果。

## 斜杠菜单图标

输入 `/` 后，四个内置命令在中文名称左侧显示 24px 猫猫图标。资源由 [builtin.ts](src/builtin.ts) 的 `builtinCommandIcons` 提供。

| 命令       | 名称 | 图像特征                 |
| ---------- | ---- | ------------------------ |
| `/plan`    | 计划 | 展开紫色路线图，爪子指图 |
| `/goal`    | 目标 | 抱着珊瑚红靶心与黄色箭   |
| `/compact` | 压缩 | 双爪将文件压进黄色纸盒   |
| `/name`    | 命名 | 举着青绿色空白名牌       |

[图标预览](command-icons-preview.png) 展示四张图及深浅底色下的小尺寸效果。
